# Football Pitch SVGs

This directory contains SVG versions of the football pitches used in the LuvFutbol tactical board editor. These SVGs match the Canvas-drawn pitches in the tactical board and are available for download or external use.

## Available Pitches

### `full-pitch.svg`
Complete football field with:
- Full field boundaries (800x600)
- Center line and center circle
- Both penalty areas and goal areas
- Penalty spots and center spot
- Corner arcs

### `attacking-half.svg`
Attacking half of the pitch featuring:
- Half field width (400x600)
- Right penalty area and goal area
- Proper semi-circle at center line
- Right corner arcs
- Penalty spot and penalty arc
- Ideal for attacking tactical drills

### `defensive-half.svg`
Defensive half of the pitch featuring:
- Half field width (400x600)
- Left penalty area and goal area
- Proper semi-circle at center line
- Left corner arcs
- Penalty spot and penalty arc
- Ideal for defensive tactical drills

### `empty-pitch.svg`
Clean green field with no markings:
- Pure green background (#4ade80)
- No field lines or markings
- Full field dimensions (800x600)
- Perfect for custom tactical diagrams

### `half-pitch-template.svg`
Half-field template showing:
- Half field width (400x600)
- Center line as boundary with proper semi-circle
- One penalty area setup
- Additional template markings (dashed 18-yard line)
- Useful for small-sided games or specific drills

## Technical Specifications

- **Full Pitch Dimensions**: 800x600 viewBox (4:3 aspect ratio)
- **Half Pitch Dimensions**: 400x600 viewBox (2:3 aspect ratio)
- **Field Color**: #4ade80 (green)
- **Line Color**: White
- **Line Width**: 2px
- **Format**: Scalable Vector Graphics (SVG)

## Usage

These SVGs are optimized for:
- Print materials and handouts
- Presentation slides
- External tactical software
- Coach training materials
- Custom tactical board applications

All SVGs maintain the same proportions and styling as the Canvas-rendered pitches in the LuvFutbol tactical board editor.

## Compatibility

These SVG files are compatible with:
- Web browsers
- Vector graphics software (Adobe Illustrator, Inkscape)
- Presentation software (PowerPoint, Keynote)
- PDF documents
- Print media

The SVGs use standard SVG syntax and should work across all modern platforms and applications.
