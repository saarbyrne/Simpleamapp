## 📐 Design Principles

### 1. Use Design Tokens
Never hardcode colors, spacing, or typography values. Always use design tokens from `@/design-system/tokens` or Tailwind semantic classes.

**Good:**
```tsx
<div className="bg-primary text-primary-foreground p-4">
```

**Bad:**
```tsx
<div className="bg-[#142978] text-white" style={{ padding: '16px' }}>
```

### 2. Mobile-First Responsive
Write mobile styles first, then add larger breakpoints (sm:, md:, lg:).

```tsx
<div className="p-4 md:p-6 lg:p-8">
```

### 3. Accessibility First
All components meet WCAG 2.1 AA standards. Include proper ARIA labels, keyboard navigation, and focus indicators.

### 4. Dark Mode Support
Use semantic color classes (bg-background, text-foreground) that automatically adapt to dark mode.

## 💡 Best Practices

1. **Always use shadcn/ui components** - Import from `@/components/ui`
2. **Use DataTable for tables** - TanStack Table via `@/components/data-table`
3. **Use semantic colors** - `bg-primary`, not `bg-blue-500`
4. **Use design tokens** - Import from `@/design-system/tokens`
5. **Test in light and dark mode** - Use the theme switcher in the toolbar
