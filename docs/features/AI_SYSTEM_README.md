# AI Assistant & Tooling System

## Overview

The AI Assistant & Tooling system provides an intelligent companion for team management, leveraging Anthropic's Claude API to help coaches and staff:

- Query and analyze player wellness, load, and performance data
- Generate insights and identify risks (injury risk, wellness decline, load spikes)
- Automate tasks (schedule events, distribute forms, create notes)
- Create reports and analyze correlations
- Provide conversational interface with natural language queries

## Architecture

### Components

1. **AI Service Layer** (`lib/ai/`)
   - `service.ts` - Core Anthropic API integration with streaming support
   - `tools.ts` - Tool definitions and execution functions (MCP-style)

2. **API Routes** (`app/api/ai/`)
   - `/api/ai/chat` - Streaming chat endpoint with tool calling
   - `/api/ai/conversations` - Conversation history management
   - `/api/ai/conversations/[id]` - Individual conversation CRUD
   - `/api/ai/insights` - AI-generated insights management
   - `/api/ai/settings` - User preferences and cost controls

3. **UI Components** (`components/ai/`)
   - `ai-chat.tsx` - Main chat interface with streaming responses
   - `conversation-history.tsx` - Sidebar with conversation list
   - `ai-insights.tsx` - Dashboard displaying proactive insights
   - `ai-settings.tsx` - Settings page for privacy controls and preferences

4. **Database Models** (Prisma schema)
   - `AIConversation` - Chat conversations
   - `AIMessage` - Individual messages with token tracking
   - `AIInsight` - Proactive insights generated by AI
   - `AISettings` - User preferences and cost controls
   - `AICostTracking` - Cost monitoring and usage tracking

## Setup Instructions

### 1. Install Dependencies

```bash
npm install
```

Required packages:
- `@anthropic-ai/sdk` - Anthropic API client
- `react-markdown` - Markdown rendering in chat
- `date-fns` - Date formatting (already installed)

### 2. Run Database Migration

```bash
npm run db:migrate
# or
npx prisma migrate dev --name add_ai_system
```

### 3. Generate Prisma Client

```bash
npm run db:generate
# or
npx prisma generate
```

### 4. Start Development Server

```bash
npm run dev
```

The AI Assistant will be available at `/dashboard/ai`

## Features

### 1. Chat Interface

- **Streaming Responses**: Real-time streaming of AI responses
- **Tool Calling**: AI can call functions to fetch and manipulate data
- **Conversation History**: Persistent conversations with auto-generated titles
- **Suggested Queries**: Quick access to common questions
- **Message Actions**: View and act on AI-created entities (events, reports, etc.)

### 2. AI Tools (MCP-Style)

The AI has access to the following tools:

**Data Retrieval:**
- `list_players` - Get players with optional filtering
- `get_player` - Get detailed player information
- `query_spreadsheet` - Query spreadsheet data
- `get_form_responses` - Get form responses with filters
- `search_notes` - Search notes by content or tags
- `list_events` - Get calendar events

**Actions:**
- `create_event` - Create calendar events
- `distribute_form` - Send forms to players
- `create_note` - Create notes

**Analysis:**
- `analyze_load_wellness` - Analyze load/wellness correlation
- `calculate_injury_risk` - Calculate player injury risk

### 3. Proactive Insights

AI monitors data and generates insights:

- **Injury Risk Alerts** - High injury risk detection
- **Wellness Decline** - Team wellness trending down
- **Load Spikes** - Acute load monitoring
- **Form Completion** - Completion rate changes

Insights are displayed in the dashboard and can be dismissed or acted upon.

### 4. Cost Tracking & Controls

- **Token Usage Monitoring** - Track input/output tokens per conversation
- **Monthly Limits** - Set and enforce monthly token limits
- **Cost Calculation** - Real-time cost estimation based on Claude Sonnet 4 pricing
- **Usage Dashboard** - Visual representation of monthly usage

### 5. Privacy Controls

Users can control what data the AI can access:

- Player wellness data
- Load/GPS data
- Medical notes
- Form responses
- Event attendance
- Private notes

### 6. Settings

- **Alert Frequency**: Real-time, daily digest, or weekly summary
- **Data Access Controls**: Granular permissions for different data types
- **Token Limits**: Set monthly usage limits
- **Alert Types**: Toggle specific insight types

## Pricing

Based on Claude Sonnet 4 pricing:
- **Input tokens**: $3 per million tokens
- **Output tokens**: $15 per million tokens
- **Average conversation**: ~5k tokens = $0.075
- **1000 conversations/month**: ~$75

The system includes:
- Real-time cost tracking per conversation
- Monthly token usage limits
- Cost estimation dashboard
- Automatic reset on the first of each month

## Troubleshooting

### "ANTHROPIC_API_KEY is not defined"
- Add your Anthropic API key to `.env`
- Restart the development server

### "Streaming not working"
- Check browser console for errors
- Verify API route is returning proper SSE format
- Check network tab for streaming response

### "Tool execution fails"
- Verify database permissions
- Check tool input validation
- Review API logs for errors

### "High costs"
- Review token usage in AI settings
- Lower monthly token limits
- Optimize prompts to be more concise
- Use caching for repeated queries
